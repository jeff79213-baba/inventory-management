# 庫存管理系統重新設計

## 資料結構

### 3個 Firestore 集合

| 集合 | 用途 | 欄位 |
|------|------|------|
| `inv_fields` | 欄位定義 | name, options[], order, showInList(bool) |
| `inv_items` | 品項名稱（最高單位） | name, createdAt |
| `inv_units` | 每個存入的單位 | itemName, fields{fieldName: selectedValues[]}, quantity, location, note, photo, createdAt |

### 資料流程
1. 後台設定 `inv_fields`：新增/刪除/排序欄位，勾選「顯示在庫存列表」
2. 庫存列表：顯示 `inv_items` 的名稱膠囊
3. 點名稱 → 從 `inv_fields` 讀取 `showInList=true` 的欄位 → 顯示膠囊選項
4. 選完 → 輸入數量 → 存入 `inv_units`
5. 下方表格顯示所有 `inv_units`，欄位對齊表頭

## UI 佈局

### 設計參考圖
使用者提供之佈局需求圖片，展示欄位膠囊選區的排列方式：

```
名稱        直徑        寬度        厚度        角度          重量
           選項 選項   選項 選項   選項 選項   選項 選項 選項
           選項 選項   選項 選項   選項 選項   選項 選項 選項
  |          |          |          |          |              |
```

- 每個欄位為一個直欄，欄位名稱在上方
- 欄位之間有垂直分隔線（黑色粗線）
- 每個欄位的選項以膠囊形式排列在名稱下方
- 選擇膠囊後，被選取的膠囊變色（藍底白字）
- 儲存後，表格顯示每行一個單位，欄位對齊表頭

### 庫存列表頁面
```
[搜尋列]
[名稱膠囊區] [＋]     ← 點名稱後下方展開欄位選項
[欄位膠囊選區]        ← 只顯示 showInList=true 的欄位，每個欄位一列膠囊
[數量/位置/備註輸入]  ← 選完膠囊後填寫
[儲存按鈕]
─────────────────────
[表格區]              ← 表頭 = 顯示欄位名稱，每行一個單位
```

```
[欄位列表]            ← 每個欄位可拖曳排序、勾選「顯示在庫存列表」

─────────────────────
[選中欄位的選項管理]  ← 點選欄位後，下方出現該欄位的選項膠囊（可新增/刪除/排序）
```

## 實作細節

### 後台設定功能
- 欄位列表：拖曳排序（HTML5 Drag API）+ 刪除
- 每個欄位有「顯示在庫存列表」開關（checkbox）
- 點選欄位名稱 → 下方展開該欄位的選項管理
- 選項管理：膠囊顯示 + 編輯/刪除/拖曳排序 + 新增（用 - 分隔）

### 庫存列表功能
- 名稱膠囊區：顯示所有 `inv_items` 的名稱
- 點名稱 → 從 `inv_fields` 讀取 `showInList=true` 的欄位 → 顯示膠囊選項
- 選完膠囊 → 輸入數量/位置/備註 → 按儲存
- 儲存到 `inv_units` 集合
- 下方表格自動更新

### 表格功能
- 表頭 = 顯示欄位名稱（依 order 排序）
- 每行一個 `inv_unit`
- 可搜尋/篩選
- 點行可編輯或刪除

### 資料遷移
- migrate.js 將舊的 `inv_items` 資料轉換成新的 `inv_items` + `inv_units` 結構
