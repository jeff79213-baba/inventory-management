# 庫存管理系統重新設計規格

## 概述
將原有庫存管理系統從傳統表格改為三層膠囊式介面，單頁雙模式（庫存列表 / 後台設定），為未來轉為桌面 APP 鋪路。

## 架構

### 單頁 index.html，雙模式切換
左上角導航切換「庫存列表」與「後台設定」模式。

### 三層統一結構（兩種模式共用）
1. **搜尋列** — 即時過濾第二層膠囊
2. **名稱膠囊區** — 所有名稱以膠囊橫排呈現，點選反白
3. **編輯區** — 根據選中膠囊顯示對應內容

## 資料模型

### Firestore 集合（前綴 `inv_`）

**inv_fields**（全域欄位池，每個欄位一份文件）
```
{
  id: "color",
  name: "顏色",
  options: ["紅色", "藍色", "白色", "黑色"]
}
```

**inv_items**（品項）
```
{
  name: "螺絲",
  quantity: 100,
  location: "A架第三層",
  photo: "base64...",
  photoPath: "C:\\照片\\螺絲",
  note: "常用",
  selectedFields: ["color", "size"],  // 使用哪些欄位
  attributes: {
    "顏色": ["紅色", "藍色"],
    "尺寸": ["M"]
  },
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

## 庫存列表模式

### 第一層：搜尋列
- 搜尋範圍涵蓋品項名稱、所有欄位值、位置、備註
- 即時過濾下方名稱膠囊

### 第二層：品項名稱膠囊
- 顯示所有品項（或搜尋過濾結果），橫排排列，寬度夠就併排，不夠自動換行
- 點選膠囊 → 反白，下方編輯區切換
- 膠囊右下角「+」按鈕：新增品項

### 第三層：編輯區

**標題列**：品項名稱 + 右側 [儲存] 按鈕

**欄位區**：使用 `flex-wrap` 橫排並列
- 只顯示品項有選用的欄位（selectedFields）
- 每個欄位一個區塊，標題在上，選項膠囊在下
- 所有選項同時展開，與其他欄位橫排並列
  ```
  ┌─ 顏色 ──┐ ┌─ 尺寸 ──┐ ┌─ 材質 ──┐
  │[紅][藍]  │ │[S][M]   │ │[鐵]     │
  │[白][黑]  │ │[L][XL]  │ │[不鏽鋼]  │
  └─────────┘ └─────────┘ └─────────┘
  ```
- 選項膠囊可複選，選中反白
- 欄位不足時可在編輯區直接新增選項

**下方區（橫排）**：
- 擺放位置（文字輸入框）
- 照片（顯示一張 + 路徑文字，點照片複製路徑）
- 數量（數字輸入）
- 備註（文字輸入，自由輸入，無膠囊）

**新增品項流程**：
1. 點「+」按鈕 → 跳出輸入品項名稱
2. **所有 inv_fields 全部列出**，每個欄位所有選項同時展開
3. 使用者勾選需要的欄位，並選擇對應選項
4. 填寫數量 / 位置 / 照片 / 備註
5. 按儲存

## 後台設定模式

### 第一層：搜尋列
- 搜尋欄位名稱，即時過濾下方膠囊

### 第二層：欄位名稱膠囊
- 顯示所有 inv_fields 中的欄位名稱
- 點選反白，下方顯示該欄位的選項管理區
- 膠囊右下角「+」按鈕：新增欄位

### 第三層：欄位編輯區

**選項膠囊**：
- 每個選項顯示為膠囊，含：
  - ≡ 拖動把手（三條橫線，觸摸式排序）
  - ✏️ 編輯按鈕（點擊變輸入框，Enter 確認）
  - 🗑️ 刪除按鈕
- 膠囊橫排 flex-wrap

**新增選項**：
- 多行文字輸入框（每行一個選項）
- 「加入」按鈕

**新增欄位流程**：
1. 點「+」按鈕 → 輸入欄位名稱
2. 顯示空選項區
3. 使用者一次新增多個選項
4. 可排序、編輯、刪除
5. 儲存後加入全域欄位池

### 欄位累積規則
- 所有欄位累積在 inv_fields 中
- 每當建立新品項，所有 inv_fields 全部出現供選擇
- 被選擇的欄位才出現在該品項的編輯區

## 未來 APP 轉換預留
- 照片欄位保留路徑欄位，方便未來桌面 APP 實現點擊開啟資料夾
- 膠囊 + flex-wrap 佈局，原生 APP 可直接對應
- 單頁式結構，減少遷移成本

## 非功能性需求
- 觸控友善（膠囊點選、拖動）
- 響應式（平板/手機可用）
- Firebase 即時同步
